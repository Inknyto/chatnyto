# Linux Packaging for ChatNyto

This directory contains build scripts to create Debian and AUR (Arch Linux) packages for ChatNyto.

## Directory Structure

- `build-all.sh` - Master build script for both Debian and AUR packages
- `build-debian.sh` - Create Debian `.deb` package
- `build-aur.sh` - Create AUR package structure (PKGBUILD)
- `x86_64/` - Release bundles (generated by Flutter build)
- `../debian/` - Debian package output directory
- `../arch/` - AUR package structure directory

## Building Packages

### Build All Packages

```bash
./build-all.sh [version]
```

Example:
```bash
./build-all.sh 1.0.1
```

### Build Debian Package Only

```bash
./build-debian.sh 1.0.1 .
```

Output: `chatnyto_1.0.1_amd64.deb`

### Build AUR Package Only

```bash
./build-aur.sh 1.0.1
```

Output: `../arch/chatnyto/` directory with `PKGBUILD` and `.SRCINFO`

## Installation

### From Debian Package

```bash
sudo dpkg -i chatnyto_1.0.1_amd64.deb
sudo apt-get install -f  # Install dependencies if needed
```

### From AUR (Arch Linux)

```bash
cd ../arch/chatnyto
makepkg -si
```

Or for an existing AUR repository:
```bash
git clone https://aur.archlinux.org/chatnyto.git
cd chatnyto
makepkg -si
```

## Dependencies

### Runtime

- GTK 3.0 (`libgtk-3-0` on Debian, `gtk3` on Arch)
- OpenGL (`libgl1-mesa-glx` on Debian, `libgl` on Arch)

### Build

- dpkg-deb (for Debian packages)
- makepkg (for AUR packages)
- tar, gzip

## Release Bundle

The release bundle is generated from the Flutter build:

```bash
cd flutter_app/chatnyto
flutter build linux --release
```

This creates `build/linux/x64/release/bundle/` which is then packaged into:
- `builds/linux/x86_64/chatnyto.VERSION.tar.gz`

## Files Installed

### Debian

- `/opt/chatnyto/` - Application bundle (binary, libraries, assets)
- `/usr/bin/chatnyto` - Launcher script
- `/usr/share/applications/chatnyto.desktop` - Desktop entry

### AUR

Same as Debian, installed via the PKGBUILD

## Troubleshooting

### dpkg dependency errors

If `dpkg` reports missing dependencies:

```bash
sudo apt-get install -f
```

### makepkg validation fails

Ensure you have `base-devel` group installed:

```bash
sudo pacman -S base-devel
```

### Application fails to start

Check library dependencies:

```bash
ldd /opt/chatnyto/chatnyto
```

Ensure GTK 3 and OpenGL libraries are installed:

**Debian/Ubuntu:**
```bash
sudo apt-get install libgtk-3-0 libgl1-mesa-glx
```

**Arch:**
```bash
sudo pacman -S gtk3 libgl
```
